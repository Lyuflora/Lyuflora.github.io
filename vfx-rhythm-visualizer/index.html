This app requests drive.file only. It can work with files it creates or files you select in the Google Drive picker. Your access token stays in memory and is not stored by this app.

OAuth setup

In Google Cloud, enable Drive API and Picker API, create an OAuth web client, and add as an authorized JavaScript origin. Keep these public identifiers restricted to your website in Google Cloud.
